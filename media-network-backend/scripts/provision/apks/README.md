# APKs for provision-tv.py

Drop the `.apk` files you want on every box here; `provision-tv.py` installs all of them.
They're git-ignored (download fresh copies from the official sources):

| App | Source |
|---|---|
| Vidar TV | GitHub Actions artifact `vidar-tv-debug-apk` (this repo) or build in Android Studio |
| RustDesk | https://github.com/rustdesk/rustdesk/releases (aarch64) |
| Tailscale | Play Store on the box, or https://pkgs.tailscale.com/stable/#android |
| Jellyfin for Android TV | Play Store, or https://github.com/jellyfin/jellyfin-androidtv/releases |
| TiviMate | Play Store |
| Stremio | https://www.stremio.com/downloads |
| Projectivy Launcher | Play Store |
