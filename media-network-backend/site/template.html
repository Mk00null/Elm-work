Architecture

TVs and the server share a private Tailscale network. Each TV's internet goes out through Mullvad. Only the Jellyfin web page is public, behind a Cloudflare login.

Setup

All code is written and in the repo. These are the steps on your hardware.

  1. Buy: 16 GB RAM, a 4–8 TB drive, one test Onn 4K Pro, optional HDHomeRun + antenna and UPS.
  2. Server: run windows\install-server.ps1, set up Jellyfin, then setup-jellyfin.py for live TV and plugins.
  3. Tunnel: setup-tunnels.ps1 -Domain yours.com for jelly.yours.com behind a login.
  4. Each TV: network debugging on, Tailscale, then provision-tv.py.
  5. Phone: Telegram bot token in .env; the dashboard is at port 8080.
  6. Check: check-services.ps1 all green, then buy the other six boxes.
