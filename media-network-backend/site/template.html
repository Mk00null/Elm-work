Privacy & security

Closed by default

No open ports

ADB, RustDesk and Jellyfin travel inside Tailscale. Routers at all five locations stay untouched.

Login wall

Cloudflare Access asks for an email code before anyone reaches the public Jellyfin page.

Server-only control

Tailscale rules let only the server talk to TVs. TVs can't see each other.

DNS filtering

NextDNS strips trackers, ads and telemetry on every box, with encrypted fallbacks.

Two-factor everywhere

Cloudflare, Tailscale, NextDNS and router admin. Passwords live in Bitwarden.

One VPN rule

Android allows one VPN at a time, so TVs run Tailscale only. Bitdefender VPN stays on phones and laptops.

Out of scope

Things you want that I can't add

These stay out of the build. Each one comes with the closest thing that is in the plan.
